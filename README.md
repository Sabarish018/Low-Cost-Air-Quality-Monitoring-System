# Low-Cost Air Quality Monitoring System

## Project Overview
This project presents a low-cost, real-time air quality monitoring system designed to detect hazardous gases such as LPG, methane (CH₄), carbon monoxide (CO), smoke, and carbon dioxide (CO₂).

## Project Components
- ESP32 Microcontroller
- MQ-2, MQ-4, MQ-9, MQ-135 Gas Sensors
- 16×2 LCD Display
- IoT connectivity via Blynk
- Real-time data logging

## Features
- Real-time gas detection
- IoT-enabled remote monitoring
- Visual and audio alerts
- Data logging with timestamps
- Low-cost implementation (~₹1,908)
